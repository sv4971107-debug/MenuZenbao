☁️ Guía: Activar Sincronización en la Nube

Si los cambios no se reflejan en tiempo real en otros celulares, se debe a que las Reglas de Seguridad de Firestore en Firebase expiran por defecto a los 30 días si creaste el proyecto en Modo Prueba.

Pasos sencillos para corregirlo (1 minuto):
  1. Entra a la consola de Firebase: console.firebase.google.com
  2. Abre tu proyecto Zenbao Menu y haz clic en Firestore Database en el menú izquierdo.
  3. Haz clic en la pestaña Reglas (Rules) arriba.
  4. Reemplaza todo el código existente por este (permite lectura y escritura): 
    rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
  5. Haz clic en el botón azul Publicar (Publish) arriba a la derecha. ¡Y listo!
